# MyPet 🐥

바탕화면에 사는 공부 도우미 펫. 급식·시간표·학사일정을 NEIS에서 가져오고, 뽀모도로 타이머·할 일·디데이를 한 곳에서 관리합니다.

## 기능

- **투명 펫** — 항상 위에 떠 있고 드래그로 옮길 수 있음. 위치 기억. 공부 중인 창의 포커스를 빼앗지 않음
- **뽀모도로** — 집중/휴식 자동 반복, 남은 시간 표시, 전환 시 알림 소리(사인파를 직접 생성)
- **집중 기록** — 오늘 집중 횟수/시간, 며칠 연속했는지
- **급식** — 점심 → (13:30 이후) 저녁 → (19:30 이후) 내일 아침 으로 자동 전환
- **시간표 / 학사일정** — 오늘 시간표, 앞으로 60일 일정
- **다음 교시 알림** — 교시 시작 5분 전에 다음 과목을 알려줌
- **할 일** — 추가/체크, 남은 개수를 펫에 배지로 표시
- **디데이** — 여러 개 등록, 가까운 순으로 표시
- **캐릭터 교체** — 다운로드 폴더의 GIF/PNG를 그대로 사용
- **트레이 아이콘 / 윈도우 시작 시 자동 실행**

## 실행

Java 11 이상 필요.

```bash
javac --release 11 -encoding UTF-8 -d classes src/MyPet.java
jar cfe MyPet.jar MyPet -C classes .
java -jar MyPet.jar
```

윈도우는 `build.bat` 을 실행해도 됩니다.

## NEIS 인증키 (환경변수)

급식/시간표/학사일정은 [NEIS 교육정보 개방 포털](https://open.neis.go.kr)의 API를 사용합니다. 인증키는 코드에 넣지 않고 환경변수 `MYPET_NEIS_KEY` 로 읽습니다.

```bat
setx MYPET_NEIS_KEY "발급받은_인증키"
```

설정 후 터미널(또는 로그인)을 다시 시작하세요. 키가 없어도 실행은 되지만 조회량이 제한됩니다.

## 학교 설정

`src/MyPet.java` 맨 위 상수를 바꾸고 다시 빌드하세요.

| 상수 | 설명 |
|---|---|
| `OFFICE` | 시도교육청코드 (예: 서울 `B10`, 광주 `F10`) |
| `SCHOOL` | NEIS 표준학교코드 |
| `TYPE` | `his` 고 / `mis` 중 / `els` 초 |
| `GRADE`, `CLS` | 학년, 반 |
| `LUNCH_END`, `DINNER_END` | 급식이 저녁 / 내일 아침으로 바뀌는 시각 |
| `PERIOD` | 교시 시작 시각 (다음 교시 알림용) |
| `NOTICE_MIN` | 교시 시작 몇 분 전에 알릴지 |

## 설정 저장 위치

`~/.mypet/settings.properties` (이름, 디데이, 할 일, 집중 기록, 캐릭터, 펫 위치). 지우면 처음 상태로 돌아갑니다.

## 구조

```
src/MyPet.java   전체 코드 (약 770줄)
  ├─ 설정 저장      Properties 파일 읽기/쓰기
  ├─ 펫/말풍선 창    JWindow + 투명 배경 + 직접 그리기
  ├─ 뽀모도로/기록   Swing Timer
  ├─ NEIS 조회      java.net.http + 정규식 파싱 (별도 스레드)
  └─ 트레이/자동실행  SystemTray, 시작프로그램 폴더
```
